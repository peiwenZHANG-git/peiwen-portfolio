## 1. 一句话标准

**细铅笔／墨线勾形 + 很薄的透明水彩 + 大面积暖象牙纸留白。画面没有边框，四周化进纸里。**

判断一张图合不合格，最快的方法是和 Home 截图并排放。如果它看起来比 Home 更"响"、更"满"、更"亮"或更"真"，就不合格。

## 2. 色板

以下颜色均从 Home 原图取样，数值为区域平均值。

```css
:root {
  /* 纸 */
  --paper:        #F7F1E7;  /* 页面底色，全站唯一 */
  --paper-shade:  #ECE8E4;  /* 云、远景、纸的暗部 */

  /* 墨 */
  --ink:          #242224;  /* 页面主标题 */
  --ink-line:     #504434;  /* 插画里的勾线（暖棕灰，不是纯黑） */
  --ink-soft:     #716D6C;  /* 副标题、正文 */
  --ink-faint:    #918E88;  /* 小标签、脚注、页码 */

  /* 自然色（插画与界面共用） */
  --sage:         #919979;  /* 树叶、枝条 icon */
  --dust-blue:    #B1B5C2;  /* 远山、天空晕染 */
  --straw:        #CEC4A6;  /* 草地、小路 */
  --butter:       #E7BC6B;  /* 小黄花、光点 */
  --rose-brown:   #AF886C;  /* Peiwen 外套、木头、皮革 */

  /* 唯一强调色 */
  --accent:       #D96A60;  /* 只用于"当前状态"，如 EN 下划线 */
}
```

使用规则：

- **饱和度上限约 35%。** 任何大面积颜色都不能比 `--butter` 更鲜艳。
- **强调色全站只用在"当前状态"上**，包括语言切换、CV 按钮和 focus 环。不要用来做装饰。
- **季节色必须向色板靠拢，不能另立一套。** 秋天用暗赭或蜂蜜色，不用橙红；春天用灰粉，不用樱花粉；冬夜用淡灰紫，不用蓝紫渐变。

## 3. 插画语言

| 维度 | 要 | 不要 |
|---|---|---|
| 线 | 细铅笔／墨线，暖棕灰，线条略断、略抖 | 无线稿的纯色块、粗黑描边、矢量等宽线 |
| 上色 | 透明薄涂，能看见纸 | 厚涂、油画颗粒、impasto 纹理、满版渐变 |
| 光 | 平光；光源用几颗小暖点表示 | 辉光、bloom、光晕、星星闪烁、镜面高光 |
| 阴影 | 物体脚下一小块淡接触影 | 大投影、强明暗、体积光 |
| 透视 | 绘本式轻微纵深，偏正面 | 强透视、广角、写实室内空间 |
| 边缘 | 无框；天空化进纸，地面用草叶笔触散开 | 矩形框、圆角框、树叶／花瓣剪影边、贴纸白边 |
| 密度 | 至少 40% 是纸或淡天空；细节集中在左右和前景 | 满版铺满的树叶、花、道具 |
| 图中文字 | 仅限地标本身（石碑、校名），手写感，尽量少 | 装饰性文字（罐子、书脊、便签上的句子） |

## 4. 景深分层

同一张图里，四个层次按以下方式处理。

- **前景**：对比度最高，勾线最清楚，可以部分遮挡中景。
- **中景**：Peiwen 和地标所在的层。颜色最完整，是视线落点。
- **背景**：降饱和、降对比、线条变淡。
- **远景**：接近 `--paper-shade` 和 `--dust-blue`，几乎不勾线，只是一层气氛。

## 6. 字体

### 6.1 三层体系

| 角色 | 字体 | 用在哪里 |
|---|---|---|
| **手写体** | Home 当前使用的那款（外观接近 Patrick Hand，**接入时核对代码里的实际字体**） | logo、导航、页面标题、场景名、节标题、脚注、按钮 |
| **正文** | **Nunito**（400 / 600） | 所有段落、经历描述、职位信息、联系方式 |
| **小标签** | Nunito 600，全大写，`letter-spacing: 0.18em` | `HCI · PRODUCT · CREATIVE TECH` 这类 eyebrow |

**全站删除衬线体。** Experience 目前的正文、公司名和导航都在用衬线体，这是跨页割裂感最主要的来源。

### 6.2 字号与行高（桌面端）

| 用途 | 字号 | 行高 | 颜色 |
|---|---|---|---|
| 页面主标题 | 44–48px | 1.2 | `--ink` |
| 场景／机构名 | 34–38px | 1.2 | `--ink` |
| 副标题 | 22–24px | 1.4 | `--ink-soft` |
| 导航 | 17–18px | — | `--ink`，选中态加下划线 |
| 正文 | 16px | 1.7 | `--ink-soft` |
| 小标签／页码／脚注 | 12–14px | 1.5 | `--ink-faint` |

### 6.3 禁止

- 文字外发光、描边、阴影。
- 长段落使用手写体（超过 2 行就改用 Nunito）。
- 同一屏里出现两款以上手写体。

### 6.4 中文（暂缓）

- 本轮只做英文版。
- 中文字体（候选：霞鹜文楷 + Noto Sans SC）等英文版完成后再定。
- 在此之前，中文模式保持现状，不做改动。

## 7. 界面外壳（全站共用组件）

### 7.1 Header

**所有页面使用同一个 Header**，Header 以 Home 当前的渲染结果为准。抽取成共用组件时，Home 的画面必须保持像素级不变；如果做不到这一点，就让其他页面去对齐 Home，不改 Home 本身。Projects 页在建立时接入这个 Header。

- **左侧**：灰绿线稿枝条（`--sage`）、手写体 "Peiwen Zhang"，下方是小标签。Experience 页当前的橙色叶子需要换掉。
- **中间**：导航使用手写体。选中态是一条细手绘下划线，颜色 `--ink`。全站只用这一种选中样式，不再使用粉色笔刷胶囊，也不再使用衬线加下划线的版本。
- **右侧**：`中 / EN` 切换，当前语言用 `--accent` 下划线标出。黑胶唱片改成扁平样式，不加投影和高光。

### 7.2 页脚小注

- 左右两侧用手写体小字，配线稿小图标（花或枝条）和一条手绘曲线，与 Home 一致。
- Experience 左下角的 "Scroll · ←→ to walk" 改用手写体。

### 7.3 图标

- 统一使用单色线稿图标，线宽和 Home 的枝条相同，颜色 `--ink-soft` 或 `--sage`。
- 不使用彩色品牌 logo（LinkedIn 蓝、GitHub 黑块）、emoji 风格图标或 app 图标式圆角方块。
- Experience 的公司小图标也改成线稿。

### 7.4 其他

- **页码**统一为 `01 / 02` 格式：两位数，斜杠两侧留空格，分母从实际章节数据读取，颜色 `--ink-faint`。
- **全站禁止卡片和面板**，包括毛玻璃、投影卡片和 HUD 式浮层。文字应该像"印在绘本留白里"。
- **插画边缘**统一使用一张手绘水彩遮罩（`mask-image`），替代现有的剪影边。


### 7.5 鼠标指针与点击反馈（已批准）

**全站：铅笔**

- **指针**：一支手绘小铅笔，黄色笔杆、粉色橡皮、暖墨色描边。笔尖就是点击位置，热点坐标为 (3, 3)。
- **悬停在链接或按钮上**：文字下方由左到右"画出"一道手绘铅笔线，用时 0.35 秒。当前所在页面的导航项保持原有下划线。
- **点击**：点击位置用铅笔画出一个不太圆的小圈，0.26 秒画完，0.7 秒内淡出。

**Experience 专属：捡起纪念品的手**

- **悬停在纪念品上**：铅笔变成一只张开的小手，热点坐标为 (15, 4)。
- **按下时**：手握起来，热点坐标为 (15, 10)；同时纪念品微微抬起、倾斜，像被拿起来一样。
- **第一次到达某一站**：纪念品飞进目录的动画保持不变。

**彩蛋：小脚印（只在插画区域内）**

- 鼠标在插画上移动后停下，身后会出现 2 到 3 个 Peiwen 的小靴子脚印，方向跟随移动轨迹，1.6 秒内淡出。
- 同一时间只出现一组；两组之间至少间隔 1.2 秒。

**实现原则**

- 指针图片用 CSS `cursor: image-set(...)` 原生替换，提供 1x 和 2x 两个尺寸，系统指针作为后备，所以跟手没有延迟。
- 画线、画圈、脚印只在精细指针设备（`pointer: fine`）上启用。开启"减少动态效果"时全部关闭，只保留静态指针。
- 触屏设备不受任何影响；文字输入框保留系统的文字光标。
- **素材**：`cursor-pencil.png` / `@2x`、`cursor-hand.png` / `@2x`、`cursor-grab.png` / `@2x`。

## 8. 出图规范

### 8.1 每次出图都要做的事

1. 附上 **Home 截图**作为风格参考图。
2. 如果画面里有 Peiwen，附上 Home 里的 Peiwen 作为角色参考图。
3. 在提示词末尾加上下面的**风格锚定段**。

### 8.2 风格锚定段（通用）

```
Match the reference image style exactly: fine warm-grey graphite and ink
linework with thin transparent watercolor washes on warm ivory paper
(#F7F1E7). Very low saturation palette: sage green, dusty blue-grey, pale
straw, soft butter yellow, muted rose-brown. At least 40% of the image is
calm paper or pale sky. No frame and no border: the edges dissolve softly
into the paper, and the ground fades out with loose grass strokes. Detail
is clustered at the sides and in the foreground, the centre stays quiet.
Gentle picture-book depth, near-frontal view.
```

### 8.3 通用排除段

```
No glow, no bloom, no lens flare, no sparkles, no specular highlights,
no cast shadows, no impasto or oil-paint texture, no saturated colors,
no blue-purple gradients, no heavy shading, no realistic rendering,
no 3D, no strong perspective, no leafy or cut-out border, no decorative text.
```

## 9.5 全站故事逻辑（已批准）

整个网站是 **Peiwen 的一个小世界**。每个页面都是这个世界里的一个地方，页面之间靠**同一个角色**和**她随身带着的东西**串起来。

| 页面 | 在世界里的位置 | 画面主体 |
|---|---|---|
| **Home** | 山坡上的路口：一边是远方的路，一边是她的小房子 | 背影站立的 Peiwen、小路、房子 |
| **Experience** | 沿着那条路走过的地方 | 三个地点的场景、行走的 Peiwen、**她收集的纪念品** |
| **Projects** | 小房子的阁楼 | 晾绳上挂着她做过的东西 |
| **About** | 房子里她的书桌 | 摊开的笔记本；**桌上放着从路上带回来的纪念品** |

**串联规则**

1. **角色只有一个。** 任何页面出现的 Peiwen，都必须是 Home 那一版的形象（白发、灰玫瑰棕外套、焦糖色斜挎包、白袜、深棕短靴）。
2. **物件会跨页面出现。** 在 Experience 里捡起的纪念品（地铁票、银杏叶、樱花），同样会出现在 About 的桌面上，而且是同一套图。新增的跨页面物件，也要先在"它被捡到的地方"出现过。
3. **材料只用这一套：** 象牙纸、铅笔线加淡彩、撕边纸片、胶带、枝条小图标、手写体加 Nunito。新页面不得引入新的材质，例如金属、皮革光泽、玻璃、霓虹。
4. **每个页面只有一个"记忆点"。** Home 是那条路，Experience 是纪念品收集，Projects 是晾绳，About 是笔记本。不要在同一页叠加两个以上的特色交互。
5. **本子和单页要区分开。** About 用装订成册的笔记本，Experience 用单页手账，两者共用纸片素材，但版式不重复。

新页面或新功能在设计前，先回答两个问题：**它在这个小世界里是哪里？它和已有的物件有什么关系？** 答不上来，就先不做。

## 11. 过渡处理：Experience 插画降饱和（已批准）

目标是让三张插画的平均饱和度接近 Home 插画区域（取样值约 0.13）。三张图原本的饱和度差距很大，所以**不能用同一个统一数值**：

| 场景 | 原始饱和度 | `saturate()` | 其他处理 | 处理后 |
|---|---|---|---|---|
| CUC | 0.385 | **0.50** | 纸色叠加 | ≈ 0.22 |
| Japan（planned，建成后使用） | 0.214 | **0.70** | 纸色叠加 | ≈ 0.15 |
| Paris-Saclay | 0.134 | **0.90** | 纸色叠加 + 轻微暖移（压掉蓝紫） | ≈ 0.14 |

注意：上表数值是在概念截图上测得的。接入时，要在 `/storybook` 实际使用的运行时资产上重新测量，把上表当作起点，目标饱和度约 0.13–0.15；CUC 的 0.50 是已批准的观感基准。

CUC 没有压到 0.13 是有意为之：压到 0.30 时整张图发灰，秋天的感觉就没了。它剩下的差距要靠重画来解决（橙红改暗赭，树叶减半）。

实现方式如下：

```css
.sceneArt            { filter: saturate(var(--scene-sat)) contrast(.93); }
.sceneArt::after     { background: var(--paper); mix-blend-mode: multiply; }  /* 叠加纸色 */
.sceneArt::before    { background: var(--paper); opacity: .10; }          /* 纸色薄洗 */
.sceneFrame          { mask-image: url(/assets/ui/edge-wash.webp); }        /* 柔边 */
[data-scene="cuc"]    { --scene-sat: .50; }
[data-scene="japan"]  { --scene-sat: .70; }
[data-scene="saclay"] { --scene-sat: .90; }
```

几点说明：

- **柔边遮罩**：先用程序生成的遮罩上线。等手绘水彩遮罩到位后，替换这一张文件即可。
- **注意范围**：降饱和只作用于插画本身，不能作用到 Peiwen 精灵上（如果她是单独一层的话），以免她和 Home 里的形象色差变大。
- **这是过渡方案，不是终点**：降饱和解决的是颜色问题，解决不了密度和笔触的问题。重画仍按第 8.4 节执行，重画完成后删除这些 filter。

## 12. 全站故事逻辑（已批准）

整个网站是 **Peiwen 的一个小世界**。每个页面都是这个世界里的一个具体地方，而不是一个功能模块。

| 页面 | 在这个世界里是什么 | 主要画面 |

### 12.1 串联规则

1. **同一个 Peiwen。** 所有页面用同一套形象，按场景只换姿势（背影站姿、侧面行走）。
2. **同一套纸质材料。** 象牙纸、撕边纸片、胶带、车票存根、枝条图标，全站共用一套资产，不在某一页单独发明新材料。
3. **物件会跨页出现。** Experience 里收集的三件纪念品（地铁票、银杏叶、压花樱花），会出现在 About 的书桌上。以后新增的经历也遵循这条：路上带走什么，家里就能看到什么。
4. **避免两页长得太像。** About 是"书桌上的笔记本"，有桌面、封面和活页环；Experience 是"一页贴在纸上的手账"，只有单页。两页可以共用纸张资产，但不共用场景。
5. **新增页面前先回答一个问题：** 它在这个小世界里是哪里？答不上来的页面，先不做。
