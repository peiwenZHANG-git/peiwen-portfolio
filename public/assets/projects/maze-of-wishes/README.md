# Maze of Wishes portfolio assets

These files were selected from the user-provided `Mazegame.zip` for the public case study.

- `demo-poster.webp` and `resources/maze-of-wishes-demo.mp4`: classroom demonstration of the phone-controlled working prototype. The public MP4 is a browser-compatible H.264 transcode of the supplied HEVC recording.
- `early-storyboard.webp` and `resources/early-storyboard.pdf`: early keyboard-maze concept. It documents the starting point, not the final interaction.
- `tilt-tutorial.webp`, `start-screen.webp`, `gameplay-overview.webp`, `potion-boost.webp`, `cake-required.webp`, `success.webp`, `timeout.webp`, `tiled-editor-crop.webp`: selected evidence exported from the supplied project documentation.
- `final-map.webp`: final illustrated map from the supplied Java project.
- `resources/project-documentation.docx`: supplied final project documentation.

Evidence boundary: the archived collision mask does not fully match the final demonstrated build, so it is not published here as proof of robust pixel-perfect collision. No raw participant data or source archive is included.
