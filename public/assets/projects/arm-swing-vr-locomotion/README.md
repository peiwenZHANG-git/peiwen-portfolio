# Arm-Swing VR Locomotion assets

Portfolio-ready derivatives for `/projects/arm-swing-vr-locomotion`.

## Provenance

- `gameplay-*.webp` and `demo-poster.webp`: frames from Peiwen Zhang's supplied `demo-zpw.mp4`.
- `speed-curve.webp`: explanatory plot redrawn from the verified final scene parameters: exponent 2.0, sensitivity 12 and maximum speed 15.
- `unity-settings.webp`, `banner-edge-case.webp`, and `coin-proximity.webp`: images published in Peiwen Zhang's 2026 IGD301 course archive at <https://u8739516597-dotcom.github.io/>.
- `testing-session.webp`, `participant-results.webp`, and `subjective-results.webp`: evaluation evidence published in the same course archive.
- `resources/arm-swing-demo.mp4`: 1280px H.264/AAC web derivative of the supplied 76-second demo; no content was added or removed.
- `resources/arm-swing-presentation.pdf`: byte-for-byte copy of the supplied final presentation.

The course environment, coin course, scoring and base task framework came from the course-provided `VR-locomotion-parkour` scaffold. The page attributes that boundary explicitly. No Unity source repository, generated build artifacts, raw participant data, or unpublished research material is included here.
